Fitness app: round 3 changes

Sample data, not live. Scroll inside a phone with the mouse wheel or trackpad. Nothing here is built yet: this is for your approval first.

1. Workout day: the All / Remaining toggle

All (always the choice when the app opens). Finished exercises are dimmed, so you can still see them.
Remaining: finished exercises disappear, so the last ones are at the top instead of 17 scrolls away.
Remaining, everything done: says so instead of showing an empty page.

2. Exercise screen: PR banner, gold dot, 1RM, main sets and warm-ups

Last session was a PR (60 kg × 16, clean form). Loud gold banner at the top with the number to take, and the last dot on the chart is gold.
Same screen scrolled: warm-ups are reference only (not logged, not counted). The circle counts main sets: 0 of 1.
Top reps but form was not clean: no gold dot, calm banner: same weight again.
Normal day: green everywhere, exactly as now.

3. Logging a set: arrows, then the clean-form question

Add set: − / + on both. Weight steps by 2.5 kg, reps by 1. Reps start in the middle of the range (8–16 → 12). Tap a number to type it instead.
Only when you reach the top of the rep range at the working weight, right after Save, one question about all the reps.
Answered Yes: counts as a PR, the 1RM and next weight appear, and the gold dot is shown now.
Answered No: logged normally, not a PR. Next time: same weight, clean reps.

4. Edit plan: main sets and warm-up sets

Each exercise gets Main sets and Warm-up sets. Existing exercises keep their sets as main sets and start with 0 warm-ups; you set them where you want them.

How the colours work (the line chart)

Green dot: a normal session.
Gold dot with ★: a PR. Top of the rep range at the working weight and form confirmed clean.
Hollow green: you reached the top reps but said the form was not clean. Not a PR.
When your last session is a PR, the exercise screen shows the gold banner and the workout list shows a gold chip. As soon as you log a session at a higher weight, the banner is gone and the new weight starts a fresh run of green dots. Gold dots from earlier PRs stay on the chart.

The 1RM maths (Epley, as your app uses today)

1RM = weight × (1 + reps ÷ 30). Next weight = 1RM ÷ (1 + minimum reps ÷ 30), rounded to the nearest 2.5 kg. No cap for now.

The 1RM is also shown after every set you log ("Est. 1RM about 92 kg"), not only on PRs.

Warm-up weights (reference only)

1 warm-up: 75%. 2 warm-ups: 75% and 90% (as today). 3 warm-ups: 60%, 75% and 90%. Never logged, never counted.

What counts as "done" on the workout list

An exercise is done when all its main sets are logged. Warm-ups are ignored. "Remaining" hides done ones.
