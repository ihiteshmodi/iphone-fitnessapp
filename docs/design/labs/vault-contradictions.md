# Vault contradictions (settle with Blood Labs)

Where the program notes give two different numbers for the same thing, the app shows both and uses **neither** in a rule. Each one should be settled in Phase B (Blood Labs) using your own tests, or by picking one with a reason.

| Topic | Value A | Value B | Where the app shows it | Settle with |
|---|---|---|---|---|
| Vitamin D sufficiency cut-off (25-OH-D) | One chapter's lower cut-off | A higher cut-off in another chapter | Supplement library → Vitamin D | Your 25-OH-D result |
| Biotin pause before blood tests | 48–72 h | 72 h | Supplement library → Biotin | Use the longer (72 h) until decided |
| Magnesium dose | 200–400 mg | 350 mg (as an upper limit for supplements) | Supplement library → Magnesium | Serum / RBC magnesium, gut tolerance |
| Vitamin B6 upper limit | 100 mg/day | 12 mg/day | Multivitamin what if (B6 is not flagged over a limit) | Use your multivitamin's label; B6 blood level if symptoms |
| Collagen dose | 10–15 g | about 15 g | Supplement library (collagen is not recommended for you anyway) | Not needed |
| Fat floor in a cut | 0.5–0.8 g/kg | 0.6–0.8 g/kg | Diet targets use 0.8 g/kg (the top of both) | Lipid panel, hormones |
| Lean gain rate (intermediate) | 0.5–1% body weight per month | 0.25–0.5% per week | Calorie advice uses the monthly rate | Your own trend |
| Protein in a cut | "Should go up" (body text) | "Should not drop", same 0.8 g/lb (summaries) | Diet targets keep the same protein in a cut | Not needed; the app keeps it the same |

Exact source chapters are in the private extraction notes (not in this public repository).
